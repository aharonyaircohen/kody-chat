# Local LinkStack

This directory contains LinkStack v4.8.6 with the Water theme, advanced appearance controls, automatic RTL support, and the imported `aharonyaircohen` profile.

Start the full application:

```bash
docker compose up --build
```

Open `http://127.0.0.1:4186`.

Local development login:

- Email: `admin@example.test`
- Password: `change-me-now`

Set `LINKSTACK_ADMIN_EMAIL`, `LINKSTACK_ADMIN_PASSWORD`, and `LINKSTACK_APP_KEY` before using this outside local development.

Appearance settings are at `/studio/appearance`. The public profile is at `/@aharonyaircohen`.
