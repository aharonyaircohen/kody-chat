# LinkStack feature checklist

This is the current local product. A feature is marked complete only when it
works in the browser and has a test.

## Current features

| Feature | Status | Test coverage |
| --- | --- | --- |
| Start the local app | Done | Browser test starts the app |
| Edit display name, bio, and public URL | Done | Browser test |
| Add a link | Done | Browser test |
| Edit a link | Done | Browser test |
| Delete a link | Done | Browser test |
| Enable or disable a link | Done | Browser test |
| Reorder links | Done | Browser test |
| Save data in the current browser | Done | Browser test reload |
| Theme selection | Done | Browser test |
| Accent color | Done | Browser test |
| Font selection | Done | Browser test |
| Button shape | Done | Browser test |
| Link spacing | Done | Browser test |
| Live builder preview | Done | Browser test |
| Public profile at `/p/<slug>` | Done | Browser test |
| Links open their saved URLs | Done | Native browser links |
| Copy public link | Done | Browser test |

## Not included yet

These are intentionally not built yet:

- Login or accounts
- Database or cloud saving
- Multiple pages
- Analytics
- Image upload
- Drag-and-drop ordering
- Custom domains

We will add these only one at a time, after agreeing on the feature and its
test.
